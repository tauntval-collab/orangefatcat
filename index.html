How a commission works

  1. Brief

    DM me what you’re building — ability list, meshes or rigs — plus the theme or references and how many effects you need.

  2. Sample

    I do one effect first so we lock the style before the full batch.

  3. Batch & revisions

    The rest of the set gets built to match. You review in Studio and call out changes.

  4. Delivery

    You get a model file with every effect already attached and named — drop it in and it works.
